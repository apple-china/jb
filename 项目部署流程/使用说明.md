# 项目部署与使用说明

## 测试环境部署

真实密钥只填写在服务器本地 `.env.dingtalk-test`，不得提交 Git：

```dotenv
MOREDIAN_ORG_ID=<机构 OrgID>
MOREDIAN_ORG_AUTH_KEY=<机构 OrgAuthKey>
MOREDIAN_DEVICE_SN=<唯一允许设备 SN>
MOREDIAN_REQUIRE_SIGNATURE=true
MOREDIAN_CALLBACK_URL=https://jb.huixinghub.top/api/v1/integrations/moredian/recognition-events
MOREDIAN_RETENTION_DAYS=180
MOREDIAN_MAX_EVENTS=60000
MOREDIAN_CLEANUP_INITIAL_DELAY_MS=300000
MOREDIAN_CLEANUP_INTERVAL_MS=604800000
```

默认每 7 天清理一次门禁原始事件；可以在 5～30 天范围内调整检查周期。事件同时受
180 天和最新 60000 条双重上限约束，命中任一条件即清理。

```bash
cd /opt/stacks/jiabei-prod
git fetch origin
git switch codex/moredian-access-attendance
git pull --ff-only origin codex/moredian-access-attendance

docker compose --env-file .env.dingtalk-test \
  -f docker-compose.yml -f docker-compose.dingtalk-test.yml config --quiet
docker compose --env-file .env.dingtalk-test \
  -f docker-compose.yml -f docker-compose.dingtalk-test.yml \
  up -d --build --force-recreate backend frontend
```

## 注册魔点回调

注册地址：

```text
https://jb.huixinghub.top/api/v1/integrations/moredian/recognition-events
```

推荐在魔点开放平台中进入“钉钉渠道云端接口应用 → 已授权机构 → 调试”，点击右上角
“一键获取 Access Token”，再进入“回调接口 → 注册回调”，填写上面的地址和
`REC_SUCCESS`。不要使用旧企业内部应用的 `/org/getOrgAccessToken`。

需要命令行注册时，先从在线调试页取得临时 AccessToken，然后执行：

```bash
cd /opt/stacks/jiabei-prod
export MOREDIAN_CALLBACK_URL='https://jb.huixinghub.top/api/v1/integrations/moredian/recognition-events'
./scripts/register-moredian-callback.sh
unset MOREDIAN_ACCESS_TOKEN
```

脚本静默读取 Token，固定调用钉钉渠道的
`https://toapi.moredian.com/callback/addOrgCallback`，并校验响应 `result` 必须为 `0`。
注册是覆盖式操作；程序重启、容器重启和服务器重启均不需要重新注册。

## 日志与验收

```bash
docker compose --env-file .env.dingtalk-test \
  -f docker-compose.yml -f docker-compose.dingtalk-test.yml \
  logs -f --since=10m backend | grep --line-buffered -E 'Moredian callback|gate-event retention'
```

- 首次合法事件：`result=ACCEPTED`。
- 同一事件重推：`result=DUPLICATE`，不重复落库。
- 验签、机构、设备、格式或处理异常：`Moredian callback alert`。
- 清理发生时：`Moredian gate-event retention completed`。

当前告警只保存在应用日志中，不发送钉钉通知。后续版本可把相同 `alertType` 接入钉钉告警。
