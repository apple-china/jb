## 最新自动化结果

- 后端常规单元测试：9/9 通过。
- PostgreSQL 16.15 集成测试：10/10 通过（取消释放、主动冲突例外、唯一超管、次数约束、并发创建、密码改密与审计同事务、卡片私有数据、乱序保护、失败重试及生产迁移不含 Mock 账号）。
- 新版 API 冒烟：20/20 通过，包含强制改密、角色边界、取消累计、冲突例外、作废删除、手动卡片、无钉钉提醒、资源排序、排班出勤和魔点签到。
- 前端 Vitest：13/13 通过，覆盖四类提示与 1 秒计时、连续提示重置、下拉互斥、有界时间滚轮、日期区间预设、第二字头像、钉钉 JSAPI 成功/失败及既有登录页。
- Playwright：14/14 通过，覆盖桌面与 360px；验证主播信息优先级、时间显示、头像退出、历史筛选、总数、分页、Excel 下载、发送卡片日期选择、角色导出边界、设置状态文案及下拉互斥。
- 前端生产构建、Spring Boot 可执行 JAR：通过。
- 真实 API 导出冒烟：运营创建 1 条临时预约后，组合筛选返回 1 条，导出 XLSX 含表头与数据行；随后已重建 Mock 数据并恢复服务。

## 本轮额外修复

- 门禁证据查询增加“不得使用未来事件”，同时保持 `T-120分钟` 为严格开区间。
- 化妆师管理端权限收敛为查看预约/化妆师/团队/主播及为本人代约，不能读取账号、系统设置、审计或发送卡片。
- 权限拒绝统一写入审计日志；更新本地钉钉 Mock 身份为五角色有效账号。
- 超管初始密码及管理员重置密码后，非 Mock 登录必须先改密；修复改密接口此前被鉴权排除导致不可用的问题。
- 修复密码修改成功时审计日志 SQL 参数不匹配导致事务回滚的问题；前端改密后使用新密码自动重新登录。
- 修复手机管理端隐藏桌面侧栏后无导航的问题，增加底部“预约/代预约/设置”。
- 本地 Mock 种子仅由 `local` 配置加载；生产迁移不再创建任何固定测试账号，生产首次启动必须由环境变量创建唯一超管并强制改密。
- 完成第三轮界面验收调整：代预约日期改为今天/明天选择；日期并入筛选；移除管理页标题区；压缩卡片发送入口；化妆师/团队/账号隐藏说明；账号按角色展示“角色 · 姓名”；时间改为小时/分钟双滚轮；工作日改为七格选择控件。
- 化妆师、团队按启用状态和更新时间排序；账号按启用状态、固定角色顺序和更新时间排序，停用项统一置后。
- 完成第四轮界面验收调整：列表内所有停用项统一置灰；系统关闭说明精简；预约管理恢复今天/明天快捷切换，筛选日期改为日历；工作日显示为带选中图标的完整“周一～周日”；小时与分钟滚轮支持首尾循环，分钟跨越 50/00 时同步切换相邻小时。
- 完成第五轮界面验收调整：顶部身份统一为“角色 · 姓名”并将超级管理员简称为“超管”；加宽移动端身份文本区域；代预约原因改为 5 个常用人工原因；发送成功提示改为悬浮显示 1 秒；双按钮底部导航等宽展示，并将“设置”改为“状态”。
- 完成第六轮 23 项页面验收调整：统一今天/明天日期组件和紧凑时间文本；小时滚轮改为有界且分钟仅跨相邻小时；主播预约卡突出四态签到、列表优先显示化妆师、头像确认退出；管理端重排工具栏、拆分签到与“时间重叠”徽标、恢复底部“设置”、图标化新增/编辑/账号入口，并修复团队保存误用化妆师工作日校验。
- 完成账号与资源模型升级：超管昵称为 Admin；设置页按化妆师、主播、团队、管理员分组并支持五行折叠；新增账号改为钉钉员工检索与强制选取，分别保存不可变钉钉 ID、钉钉用户名和可编辑昵称；管理员/主播支持角色切换及固定初始密码的分配、复制与回收；数据库、实体及公开 API 字段统一为 makeup artist 命名。
- 新增全局单开的自定义下拉框和屏幕中上部四类悬浮提示，瞬时结果默认 1 秒消失且新提示重置计时；持续系统状态仍保留页内展示。
- 登录页增加“钉钉免登”，前端通过 `dd.requestAuthCode` 获取一次性码并复用现有后端登录接口；Docker 支持注入公开构建标识 `VITE_DINGTALK_CLIENT_ID`、`VITE_DINGTALK_CORP_ID`，未引入前端密钥。
- 修复总测试脚本在未配置全局 Maven 时无法运行、Maven 失败仍可能继续并误报完成的问题：现会自动使用项目内 JDK/Maven、固定用户依赖缓存，并对非零退出立即失败。
- 完成第七轮 13 项补充验收：管理端恢复默认今天/明天并将历史高级筛选改为按需展开；保留总数、分页、筛选导出与发送卡片。设置页头像恢复首字，四类栏目显示启用/总数及图标化展开，化妆师账号与排班合并为单一编辑入口；钉钉员工按需显示并同步昵称，密码分配/回收互斥，无变更保存不发请求。登录按钮要求账号和密码均超过 6 位，主播预约卡顶部改为唯一签到状态徽标。
